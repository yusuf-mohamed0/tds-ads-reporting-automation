# Traffic Digital Solutions — Brand Assets

Source: SharePoint brand folder (downloaded 2026-08-23)

## Files
- `Traffic_brandbook_V4.pdf` — Official brandbook with colors, typography, logo usage
- `Logo.zip` — All logo variations (PNG, AI, DXF, Google Ads sizes)
- `logos/Traffic Logo - Black - Transparent Background.png` — Black logo for light backgrounds
- `logos/Traffic Logo - White - Transparent Background.png` — White logo for dark backgrounds

## Brand Colors (from brandbook)
### Primary (use 70-100% of layout)
- `#171414` — Dark/Black (primary text)
- `#FCB900` — Gold/Orange (accent, CTAs)
- `#FCF6F2` — Cream (backgrounds)

### Secondary (max 30%)
- `#3D3B3B` — Dark Gray
- `#F89D4B` — Orange
- `#838081` — Gray
- `#FFD498` — Light Orange
- `#142444` — Dark Blue
- `#769ACC` — Light Blue

## Typography
- **Primary**: Proxima Nova (professional)
- **Secondary**: Reenie Beanie (playful accents only)
- **Fallback**: Shadows Into Light (when Reenie Beanie unavailable)

## Rules
- Headlines: Bold weight minimum, ALL CAPS for main headlines
- Limit to 3 font weights per design
- Reenie Beanie: short complementary text only, never full paragraphs
- Kerning: increase for relaxed feel
